# 🌐 Portfólio | Discovery 42 São Paulo

Projeto de portfólio desenvolvido durante o **Discovery da 42 São Paulo**, uma experiência prática de desenvolvimento web e colaboração em equipe.

O projeto foi desenvolvido em parceria, com o objetivo de colocar em prática conceitos de **HTML e CSS**, organização de páginas, estruturação de conteúdo e estilização de interfaces.

## 👩🏻‍💻 Sobre o projeto

Este portfólio reúne informações e apresentações dos integrantes da equipe, utilizando uma estrutura simples e responsiva para apresentar nossos perfis e experiências.

Durante o desenvolvimento, tivemos a oportunidade de praticar não apenas conhecimentos técnicos, mas também **colaboração, comunicação, organização e resolução de problemas**.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
